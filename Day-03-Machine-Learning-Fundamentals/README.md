# Day 3 – Machine Learning Fundamentals

## Overview

This notebook demonstrates the complete machine learning workflow using the preprocessed Titanic dataset created in Day 2. Multiple classification models are trained, evaluated, and compared.

- Loading Preprocessed Data
- Train-Test Split
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Model Evaluation
- Confusion Matrix
- Classification Report
- Model Comparison
- Saving Trained Models

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Project Structure

- `machine_learning_models.ipynb` – Model training notebook
- `models/` – Saved machine learning models
