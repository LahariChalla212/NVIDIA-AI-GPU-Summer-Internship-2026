# Day 4 – Deep Learning with TensorFlow

## Overview

On Day 4 of the NVIDIA AI GPU Summer Internship, I explored Deep Learning using TensorFlow and Keras by implementing two image classification projects.

The focus was on understanding the complete deep learning workflow, including image preprocessing, building Artificial Neural Networks (ANNs), training models, evaluating performance, and saving trained models.

---

## Projects

### 1. Rock Paper Scissors Image Classification

Built an Artificial Neural Network (ANN) to classify images into three categories:

- ✊ Rock
- ✋ Paper
- ✌️ Scissors

### Features

- Dataset loading using TensorFlow
- Image normalization
- ANN model construction
- Model training and validation
- Test dataset evaluation
- Accuracy and loss visualization
- Model saving

---

### 2. Fashion MNIST Classification

Developed an ANN to classify clothing images into ten different fashion categories.

### Categories

- T-shirt/Top
- Trouser
- Pullover
- Dress
- Coat
- Sandal
- Shirt
- Sneaker
- Bag
- Ankle Boot

### Features

- Built-in TensorFlow dataset
- Data preprocessing
- Neural network training
- Prediction on unseen images
- Performance evaluation
- Accuracy and loss graphs
- Model saving
