# Day 2 – Data Preprocessing

## Overview

Day 2 focused on preparing raw data for machine learning models. I explored essential preprocessing techniques such as handling missing values, encoding categorical features, feature scaling, and data exploration.

## Topics Covered

- Data Loading
- Exploratory Data Analysis (EDA)
- Missing Value Handling
- Duplicate Removal
- Label Encoding
- One-Hot Encoding
- Feature Scaling
- Data Cleaning

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

## Key Learning

Learned how preprocessing improves data quality and prepares datasets for effective machine learning model training.
