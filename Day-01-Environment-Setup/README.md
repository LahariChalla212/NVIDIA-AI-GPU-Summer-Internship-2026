# Day 1 – NVIDIA AI GPU Environment Setup

## Overview

The first day of the NVIDIA AI GPU Summer Internship focused on setting up a GPU-enabled development environment using Kubernetes. This session introduced containerized AI development and GPU resource allocation for machine learning workloads.

## Topics Covered

- Kubernetes Pods
- YAML Configuration Files
- CPU and Memory Allocation
- NVIDIA MIG (Multi-Instance GPU)
- GPU-enabled PyTorch Environment
- Containerized AI Development

## Hands-on Activity

- Configured a Kubernetes Pod using a YAML configuration file.
- Allocated CPU, memory, and GPU resources.
- Learned how AI workloads are deployed inside GPU-enabled containers.

## Technologies Used

- Kubernetes
- YAML
- NVIDIA GPU
- NVIDIA MIG
- PyTorch
- Linux

## Files

| File | Description |
|------|-------------|
| `pytorch-pod.yaml` | Kubernetes Pod configuration for a GPU-enabled PyTorch environment. |

## Key Learning

This session helped me understand how GPU resources are allocated using Kubernetes and how AI applications run inside containerized environments.
